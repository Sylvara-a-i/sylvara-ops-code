## Provenance and Writing Method

- **Names and connector descriptions:** exact labels and concise, faithful derivatives of the connector annotations supplied on 2026-08-14. The `Concise Description` column is connector-attributed, not a reconstructed endpoint schema or a quotation from public Zoho documentation.
- **Official documentation:** current first-party Zoho Catalyst product help, API/SDK references, and official MCP examples were reviewed on 2026-08-14. The Source Key on every row routes to the most relevant official family below.
- **Use cases:** each `Use when...` sentence is a practical derivative of the captured action effect and the cited official family documentation. It is guidance, not a provider guarantee or approval to execute.
- **Coverage boundary:** where a matching public action page exists, the public reference supports the resource effect. Where it does not, the official help supports only the product concept and the exact MCP operation remains connector-provided.
- **Risk labels:** `High Risk` is a conservative Sylvara operator label for destructive, access-affecting, externally visible, execution-triggering, or deployment-impacting actions. It is not a Zoho classification and is not exhaustive.
- **Sanitization:** this derivative contains no connection aliases, tenant identifiers, project identifiers, endpoints, credentials, live schemas, payloads, records, or logs.

Several labels intentionally preserve the interface's capitalization, including `Delete API route`, `Get API route`, `List All API route`, `Import QuickML Dataset From Zoho Crm`, and `Redeploy a deployment`. No Search, Event Listener, or generic Zia action appeared in the captured 189, so none was added from the broader Catalyst product surface.

## Reconciliation Notes

1. The official MCP overview says the full server contains more than 100 tools; **189** is the count in this dated supplied interface, not a permanent product guarantee.
2. Official MCP examples demonstrate `Execute Function Via PATCH`, while the public Execute Function REST page lists GET, POST, PUT, and DELETE. Treat PATCH as MCP-specific and inspect its live schema.
3. Public Data Store REST documentation covers row operations and metadata reads, not the captured table/column and permission/scope writes.
4. `Create Env Variables` and `List All Env Variables` refer to a deployment resource; `Update Environment Variable` refers to a function. Do not treat the scopes as interchangeable.
5. QuickML numeric type codes, defaults, internal configuration endpoint names, algorithm enumerations, filter values, and mutability limits remain connector-attributed unless a current exact action contract confirms them.
6. The generic Pipeline tools are Catalyst CI/CD tools. QuickML pipeline tools are separately named and documented.
7. Project API CORS, Stratus bucket CORS, and Authentication authorized domains are distinct controls.
8. Creating a Mail domain does not prove it is verified or ready to send; follow the current domain and DNS verification requirements.
9. Build and rollback scope is resource- and state-dependent; inspect the current contract and target before acting.
10. Detailed deletion cascades in the captured descriptions remain connector wording unless a direct official action page confirms them.
