# Sylvara Operating Standards

This directory contains durable, product-neutral instructions for how Sylvara work is reviewed and presented. These standards supplement the repository-root [`AGENTS.md`](../../AGENTS.md); product, legal, accounting, copywriting, security, and Zoho controls remain authoritative for their own scopes.

## Standards

- [Document Drafting And Typography](document-drafting-standard.md) defines portable typography, page structure, accessibility, versioning, and visual QA for user-facing artifacts.
- [Document Style Profile](document-style-profile.json) provides the machine-readable defaults used by document generators and regression tests.
- [Code Review](code-review.md) defines findings-first review, severity, evidence, context-specific gates, and the review output contract.

## Use Rules

1. Apply the narrowest applicable domain instruction before these general standards.
2. Prefer the simplest robust deliverable that solves the approved business problem.
3. Record a justified exception when a mandatory form, accessibility need, platform constraint, or approved brand requirement overrides a default.
4. Do not treat a polished document, clean review, passing test, or merged pull request as production, publication, financial, legal, or customer-communication approval.

## Portability Boundary

These standards are Sylvara-original, sanitized synthesis of authorized operating preferences. They contain no source-repository path, private source fingerprint, customer data, tenant configuration, real-estate law, property workflow, financial record, credential, or production identifier.
